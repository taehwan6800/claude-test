# 카페 일상글 샘플 도우미

이 프로젝트는 카페 운영자가 회원들에게 나눠줄 "샘플 글"을 만드는 작업이다.
회원들은 이 샘플 글을 그대로 쓰는 게 아니라, **자기 일상에 맞게 변형해서** 쓴다.
그러니 특정 제품명·구체적 사실보다는, 누구나 자기 얘기로 바꿔 쓰기 쉬운 "틀"이 되는 글이 더 좋다.

## 진행 순서 (/cafe 를 치면 이 순서대로)

1. **메뉴 제시** — 아래 3개를 보여주고 선택받는다.
   1. 웹서버 켜기
   2. 일상글
   3. 테마글 *(차후 구현 예정 — 선택 시 "아직 준비 중이에요"라고만 안내)*

2. **"웹서버 켜기" 선택 시** — 아래 "웹서버 켜는 방법"대로 처리하고, 메뉴로 돌아가지 않고 끝낸다.

3. **"일상글" 선택 시** — 몇 개 만들지 묻는다.
   - 1개 / 5개 / 10개

4. **개수 선택 후** — `guides/천안아산_동네사람들_일상글_지침.md`의 규칙을 반드시 지켜서
   선택된 개수만큼 샘플 글(제목 + 본문)을 바로 작성해서 보여준다. 추가 질문 없이 바로 만든다.
   - **`guides/페르소나.md`의 6개 페르소나 중에서 골고루 배정**해서, 글마다 다른 사람이 쓴 것처럼
     말투·ㅋㅋㅎㅎㅠㅠ 빈도·문장 길이·줄바꿈·오타 습관이 뚜렷하게 구분되게 한다.
   - 개수가 여러 개면 게시판·소재·말투·문장부호 습관·마무리 방식이 서로 겹치지 않게 다양화한다.
   - 각 샘플은 번호를 매기고, `게시판 / 제목 / 본문` 형태로 보기 좋게 정리한다.

5. 다 보여준 뒤, 사용자 확인 없이 바로 저장소(웹페이지)에 등록한다 (아래 "저장 방법" 참고).
   - 이때 웹서버가 꺼져 있으면 "웹서버 켜는 방법"대로 같이 켜준다.

## 웹서버 켜는 방법

1. `http://localhost:4500/` 에 요청을 보내 이미 켜져 있는지 먼저 확인한다 (응답이 오면 이미 켜진 것).
2. 이미 켜져 있으면 "이미 켜져 있어요, http://localhost:4500 으로 들어가시면 돼요" 라고 안내한다.
3. 꺼져 있으면 프로젝트 폴더에서 `node cafe-server.js` 를 백그라운드로 실행한다.
4. 실행 후 다시 `http://localhost:4500/` 에 요청해서 정상적으로 켜졌는지 확인한다.
5. 사용자에게 "웹서버 켰어요! 브라우저 주소창에 http://localhost:4500 을 입력해서 들어가시면 돼요" 라고 쉬운 말로 안내한다.
6. 컴퓨터를 껐다 켜거나 서버를 종료하면 다시 꺼지니, 다음에 켜고 싶을 때도 `/cafe` → "웹서버 켜기"를 누르면 된다고 알려준다.

## 일상글 작성 규칙 (필독)

**일상글을 만들 때는 반드시 `guides/천안아산_동네사람들_일상글_지침.md` 파일을 먼저 읽고
그 안의 규칙을 그대로 따른다.** 이 지침이 이 작업의 유일한 품질 기준이다.

핵심만 요약하면:

- **AI 티 나는 패턴 금지**: "상황 설명 → 고민 → 일반론 → 여러분은 어떠세요?" 같은 뻔한 구조,
  "처음에는 별일 아닌 것처럼...", "혹시 이런 경험 있으신 분 계세요?" 같은 범용 문장 반복 금지
- **본문은 구체적 장면에서 바로 시작** (예: "퇴근하고 현관문 열었는데 택배가 세 개나 쌓여있더라구요ㅋㅋ")
- 각 글에 **구체적 행동·시간·장소·실제 대화·감정·예상 못한 사건 중 최소 2개 이상** 포함
- 글마다 **작성자가 다른 사람인 것처럼** 문장 길이·말투·`ㅋㅋ`/`ㅎㅎ`/`ㅠㅠ` 사용 빈도를 다르게
  (`guides/페르소나.md`의 6개 페르소나를 골고루 배정해서 적용)
- **제목을 본문 첫 문장에서 그대로 반복하지 않기**
- 방문/사용 근거 없는 **허위 후기 금지** — 정보성 글은 "가보신 분 계세요?" 같은 질문형으로
- 마무리도 질문/혼잣말/결정/웃음/짜증 등으로 다양하게 분산 (같은 질문형 마무리 반복 금지
- 지침 안의 **게시판별 소재 범위, 장문/일반 비율, 댓글·대댓글 형식**도 요청 내용에 맞게 참고
- **마침표(.) 절대 사용 금지** — `.`, `..`, `...` 전부 빼고 쓴다. 문장 끝은 그냥 띄어쓰기로 끝내거나
  `ㅋㅋ`/`ㅎㅎ`/`ㅠㅠ`/`~`/`!`/`?` 등으로 마무리한다 (제목·본문·댓글·대댓글 모두 동일하게 적용)

샘플 개수가 적을 때(1~10개)는 지침의 "150개/게시판별 정확한 개수" 항목을 그대로 강제하지 않아도 되지만,
**글쓰기 품질·톤·금지 패턴 규칙은 개수와 무관하게 항상 지킨다.**
사용자가 "150개 다 만들어줘", "오늘 발행분 만들어줘" 처럼 정식 일일 발행을 요청하면
그때는 지침의 게시판별 수량·비율·중복 검사·댓글 형식까지 전부 그대로 따른다.

## 게시판 목록 (지침 기준)

자유수다(90) · 질문해요(5) · 우리동네 이야기(5) · 지역 뉴스·행사(5) · 병원·약국·생활업체 후기(5) ·
교통·주차·생활팁(5) · 동네 맛집 추천(5) · 카페·디저트 추천(5) · 배달·포장 후기(5) ·
오늘의 건강관리(5) · 운동·산책·식단(5) · 건강템 후기(5) · 중고거래·나눔(5)

샘플을 소량 만들 때는 이 중에서 다양하게 골라 섞는다 (자유수다 비중을 가장 높게).

## 저장 방법

새 글을 만들기 전에 `카페글_기록.md`를 읽어서 최근 제목/소재와 겹치지 않게 한다.

글을 다 보여준 뒤 별도로 묻지 않고 바로 저장소에 등록한다:

1. `cafe-storage/samples.json` 파일을 읽어서 현재 목록을 확인한다.
2. 새로 만든 글들을 아래 형식으로 이어붙여 다시 저장한다.
   (id는 기존 최댓값 + 1부터, createdAt은 오늘 날짜 `YYYY-MM-DD`, category는 게시판명,
   comments는 배열 — **글마다 3종류 중 하나로 섞어서 쓴다: 댓글 없음(`[]`) / 댓글 1개(`{ "comment": "..." }`, reply 생략) / 댓글 1개 + 대댓글 1개**. 지침의 "댓글·대댓글 3쌍" 규칙은 이 프로젝트에서는 적용하지 않는다. 비율은 대략 없음 4 : 댓글만 3 : 댓글+대댓글 3)

```json
{
  "id": 7,
  "category": "자유수다",
  "title": "...",
  "body": "...",
  "cafe": "써본언니들",
  "comments": [
    { "comment": "...", "reply": "..." }
  ],
  "createdAt": "2026-09-17"
}
```
3. `카페글_기록.md`에도 아래 형식으로 함께 기록한다:

```
### {게시판}
- 제목: {제목}
```

(날짜가 바뀌었으면 `## YYYY-MM-DD` 헤더도 새로 추가)

회원들은 `node cafe-server.js` 실행 후 `http://localhost:4500` 에서 저장된 글을 보고
제목·본문·댓글을 각각(또는 전체) 복사해서 자기 얘기로 바꿔 쓴다. 서버가 켜져 있어야 새로고침 시 최신 글이 보인다.

글을 실제로 가져다 썼으면 카드의 "사용함" 체크박스를 누른다 — 1분 뒤 자동으로
"사용된 글" 탭(상단 홈 옆)으로 이동해서, 아직 안 쓴 글과 이미 쓴 글을 구분할 수 있다.

## 주의사항

- 여러 편을 한 번에 요청받으면, 서로 게시판·소재·말투가 겹치지 않게 다양화한다.
- 사용자가 컴퓨터/용어에 익숙하지 않을 수 있으니, 결과물만 깔끔하게 보여주고 기술적인 설명은 최소화한다.
- 실제 제품명/브랜드명이나 특정 업체 후기는 방문·사용 근거가 없으므로 지침 10번 규칙대로
  질문·정보공유 요청 형태로 전환해서 쓴다.
